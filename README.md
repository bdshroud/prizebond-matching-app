# PrizeBond Matching App

> A free, open-source offline desktop application for managing and checking Bangladesh Prize Bond numbers against official draw results.

## ✨ Overview

PrizeBond Matching App helps users securely store Bangladesh Prize Bond numbers on their computer and instantly compare them with official draw results.

The application is designed to work completely offline, keeping users' data private while providing a fast and simple experience.

---

## 🚀 Features

### Current Features

* Store unlimited Prize Bond numbers
* Add, edit and delete bond numbers
* Save official draw results
* One-click winner matching
* Instant match notification
* Offline SQLite database
* Fast search and filtering
* Import and export data
* Dark mode support
* Modern desktop interface

### Planned Features

* Auto Bangladesh Bank result synchronization
* Android application
* Cloud backup and restore
* Desktop notifications
* Multi-language support
* PDF and Excel export
* Statistics and reports
* Automatic backup

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/prizebond-matching-app.git
```

Open the project:

```bash
cd prizebond-matching-app
```

Install dependencies:

```bash
npm install
```

Start development:

```bash
npm run dev
```

Run the desktop application:

```bash
npm run electron
```
