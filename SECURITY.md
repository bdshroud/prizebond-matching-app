# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Privacy & Security Guarantees

PrizeBond Matching App is designed with an offline-first architecture:
- No remote telemetry or user tracking.
- All user bond collections and match histories are stored locally inside the user's local SQLite database.
- Context isolation and secure preload IPC communication prevent arbitrary code execution from the renderer process.

## Reporting a Vulnerability

If you discover a security vulnerability in PrizeBond Matching App, please report it via GitHub Security Advisories or contact the maintainers directly. Please do not report security vulnerabilities through public GitHub issues.
